# AI 数字人医疗小助手 - 用户手册

欢迎使用 AI 数字人医疗小助手系统。本手册将指导您如何使用管理端、医生端及患者端（小程序）的各项功能。

---

## 1. 管理端使用指南

管理端面向系统管理员，提供全方位的后台资源管理与监控功能。

### 1.1 系统登录
- **访问地址**: 通常为部署后的 Web 根路径（例如 `http://admin.example.com`）。
- **默认凭据**: 
  - 账号：`admin`
  - 密码：`admin123`
- **操作步骤**: 输入账号密码后点击“登录”，系统将验证权限并跳转至数据看板。

### 1.2 数据看板 (Dashboard)
- **功能描述**: 实时展示系统的核心运行指标。
- **界面要素**:
  - **统计卡片**: 展示今日预约数、累计用户数、科室总数、医生总数等。
  - **趋势图表**: 展示近 7 日预约量的动态变化曲线。
  - **快捷入口**: 提供常用功能（如用户审核、预约处理）的快速跳转。

### 1.3 用户管理
- **路径**: 侧边栏 -> 系统管理 -> 用户管理
- **功能**:
  - **列表查询**: 支持按用户名、手机号、状态进行搜索。
  - **状态切换**: 通过开关按钮一键启用或禁用用户账号。
  - **角色分配**: 为用户分配 `ADMIN`（管理员）、`DOCTOR`（医生）或 `PATIENT`（患者）角色。

### 1.4 科室管理
- **路径**: 侧边栏 -> 医疗资源 -> 科室管理
- **功能**:
  - **CRUD 操作**: 创建新科室、编辑科室信息（名称、简介）、删除科室。
  - **状态管理**: 开启或关闭科室对外挂号的功能。

### 1.5 医生管理
- **路径**: 侧边栏 -> 医疗资源 -> 医生管理
- **功能**:
  - **入驻管理**: 绑定系统用户为医生角色，并关联所属科室。
  - **信息编辑**: 维护医生的职称、擅长领域、个人简介等核心数据。

### 1.6 知识库管理
- **路径**: 侧边栏 -> AI 引擎 -> 知识库管理 / 文档管理
- **功能**:
  - **知识库创建**: 创建不同主题的知识库（如“内科百科”、“就医流程”）。
  - **文档上传**: 上传 PDF、Word 或 Markdown 文档，系统将自动进行分块处理。
  - **分块查看**: 查看文档被 AI 切分后的原始片段及向量化状态，确保 RAG（检索增强生成）数据质量。

### 1.7 会话管理 (对话管理)
- **路径**: 侧边栏 -> AI 引擎 -> 对话管理
- **功能**:
  - **审计记录**: 查看全系统所有患者与导诊 Agent 的对话记录。
  - **质量回溯**: 监控 AI 回答的准确性，用于后续 Prompt 优化。

### 1.8 预约管理
- **路径**: 侧边栏 -> 挂号业务 -> 预约管理
- **功能**:
  - **全量列表**: 监控全院预约单，支持按医生、患者、时间范围筛选。
  - **异常处理**: 管理员可干预取消异常预约单。

### 1.9 系统配置
- **路径**: 侧边栏 -> 系统管理 -> 系统配置
- **功能**:
  - **AI 参数设置**: 配置 LLM 模型（如 DeepSeek/Qwen）的温度、最大 Token 数等。
  - **界面自定义**: 调整系统名称、Logo 等基础展示信息。

## 2. 医生端使用指南

医生端面向临床医生，专注于个人排班、患者接诊及专业百科查询。

### 2.1 个人画像维护 (我的画像)
- **操作步骤**: 
  - 进入“我的画像”页面。
  - 上传个人职业照，完善擅长病种及学术背景信息。
  - 这些信息将直接展示在小程序端的医生详情页中。

### 2.2 排班管理 (我的排班)
- **功能**:
  - **模板设置**: 配置每周固定的出诊时间段（如周一上午、周三下午）。
  - **号源生成**: 选择日期范围，一键根据模板生成可预约的号源（Slot）。
  - **实时调整**: 对特定日期的号源进行加号或停诊处理。

### 2.3 预约查看 (预约患者)
- **功能**:
  - **日程清单**: 以日历或列表形式查看未来几天的预约患者。
  - **患者背景**: 提前查看预约患者的基本信息及预填的症状描述。

### 2.4 患者对话摘要 (AI 摘要)
- **核心功能**:
  - 针对每条预约记录，医生可点击“查看摘要”。
  - 系统会自动提取患者与导诊 AI 之前的多轮对话内容。
  - **输出结果**: 包含“主要症状”、“发病时间”、“既往史”、“初步分诊建议”等结构化报告，大幅提升接诊效率。

### 2.5 百科助手 (AI Assistant)
- **功能**:
  - 内置基于 RAG 技术的医疗专业百科 Agent。
  - 医生可输入专业医学名词或指南疑问，AI 将基于私有知识库提供精准参考文献及临床建议。

## 3. 患者端(小程序)使用指南

患者端基于微信小程序，通过 3D 数字人提供自然、温馨的服务体验。

### 3.1 首页导航
- **入口**: 打开“智能医疗助手”小程序。
- **板块**:
  - **顶部**: 智能导诊入口（点击开启数字人对话）。
  - **中部**: 常用科室快捷入口、热门医生推荐。
  - **底部**: 导航栏包含“首页”、“预约清单”、“个人中心”。

### 3.2 智能导诊 (AI 问诊)
- **操作步骤**: 
  - 点击首页“开始导诊”。
  - **数字人交互**: Live2D 数字人将现身并通过语音+文字向您问好。
  - **症状描述**: 您可以通过打字或语音描述症状（如“我最近总是头晕”）。
  - **多轮引导**: AI 将追问伴随症状，并实时给出科室推荐。
  - **TTS 播报**: AI 的回复会同步转化为语音播报，增加亲和力。

### 3.3 找医生与预约
- **流程**:
  1. 在“找医生”列表中按科室筛选。
  2. 点击进入医生详情页，查看医生简介及评价。
  3. 点击“立即预约”，进入选号页面。
  4. 选择合适的日期及时间段（上午/下午的具体时段）。
  5. 确认预约信息并提交。

### 3.4 预约查看与取消
- **路径**: 底部导航 -> “我的预约”
- **功能**:
  - **列表展示**: 查看“待就诊”、“已完成”、“已取消”的记录。
  - **详情查看**: 点击预约单查看具体就诊地点、医生提醒及预约凭证。
  - **一键取消**: 在就诊时间前，可点击“取消预约”释放号源。

### 3.5 个人中心
- **功能**:
  - **个人资料**: 完善真实姓名、身份证号、手机号（用于医院同步记录）。
  - **设置**: 调整数字人声音、语音播报开关等偏好设置。
